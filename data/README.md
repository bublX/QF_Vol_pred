# Данные проекта

В Git храним исходный архив минутных цен и его описание. Распакованные CSV и результаты обработки создаются локально и исключены из Git.

```text
data/
  archives/1m_2014_2025/
    prices_1m_2014_2025.zip
  raw/1m_2014_2025/
    prices_1m_2014_2025.csv
  processed/
    10m_default_2014_2025/
    5m_2014_2025/
    10m_2014_2025/
```

## Исходный набор

Архив содержит общую таблицу минутных цен закрытия десяти акций MOEX за 2014–2025 годы. Это цены `close`, а не полные свечи OHLCV. Значения отсутствующих наблюдений остаются пустыми; архив не заполняет их и не фильтрует выбросы.

В таблице 2 031 337 строк: столбец `date` и цены закрытия VTBR, SBER, LKOH, ROSN, NVTK, TATN, GAZP, GMKN, NLMK, MGNT. Фактический диапазон временных меток — с 2014-01-06 10:00:59 по 2025-12-30 23:49:59. Точный запрос и дата первоначальной выгрузки не сохранены.

## Подготовка после клонирования

Из корня проекта, в PowerShell:

```powershell
Expand-Archive -LiteralPath "data/archives/1m_2014_2025/prices_1m_2014_2025.zip" -DestinationPath "data/raw/1m_2014_2025"
```

Если CSV уже распакован и готов к использованию, повторная распаковка не нужна.

Альтернатива распаковки для Git Bash после установки окружения проекта:

```bash
uv run python -m zipfile -e data/archives/1m_2014_2025/prices_1m_2014_2025.zip data/raw/1m_2014_2025
```

## Обработка

Повторное скачивание для комплектного набора не требуется. Выберите конфиг и выполните `process`, затем обучение:

```bash
uv run python main.py --config configs/har_5m.yaml --stage process
uv run python main.py --config configs/har_5m.yaml
```

| Конфиги | Каталог обработки | Итоговый интервал | Полуширина Хампеля, баров |
|---|---|---|---|
| `har.yaml`, `rf.yaml`, `xgb.yaml`, `lgbm.yaml` | `10m_default_2014_2025/` | 10 минут | 5 |
| `har_5m.yaml` | `5m_2014_2025/` | 5 минут | 5 |
| `har_10m.yaml` | `10m_2014_2025/` | 10 минут | 10 |

Каталоги относительны `data/processed/`. Раздельные пути сохраняют существующие различия настроек. В каждом каталоге обработчик создаёт `RV/`, `rv_matrix.csv`, `profit_matrix.csv` и `missing_days.csv`. Повторный `process` с тем же каталогом перезаписывает его результаты. Ноутбуки анализа используют стандартный десятиминутный набор: перед запуском выполните `process` с `configs/har.yaml`.

Для нового скачивания остаётся этап `load`. Настройте тикеры, годы, `source_interval`, `raw_dir` и `raw_file`; выбирайте отдельный путь, чтобы сохранить комплектный исходник. `data.interval` определяет последующую агрегацию. Параметры и алгоритмы обработки на этом этапе реорганизации не изменены.
